# Skills Overview

This repository uses a root workflow skill and five subskills for AI-driven auto testing.

## Root Skill

- `auto-testing-workflow`

## Subskills

1. `01-design-test-cases`
2. `02-execute-test-plan`
3. `03-key-step-screenshots`
4. `04-analyze-screenshots`
5. `05-test-assertions`

## Directory Convention

Each subskill uses the same internal layout for future expansion:

- `references/` for method docs and templates
- `scripts/` for executable automation helpers
- `assets/` for sample files and artifacts
